# Éditer les annotations

## Activer l’édition

1. Activez le **Mode édition** avec le bouton stylo ou le menu de l’application.
2. Appuyez sur **Ctrl+Alt+A**, saisissez **6895**, puis validez.
3. Le code est conservé sur votre profil local. À chaque lancement, activez
   le mode édition avec le stylo pour modifier des annotations.

**Ctrl+Alt+L** affiche les codes enregistrés. **Ctrl+Alt+P** propose de les
effacer et remet le profil en consultation seule. Ces commandes sont également
accessibles depuis le menu principal. Un code est une autorisation locale,
pas un compte ni une protection de sécurité.

Cette procédure reprend celle décrite par Tixu dans les [archives du forum
WoWCartographe](https://wowcarto.forumgaming.fr/t198-a-lire-en-priorite-edition-d-annotations-editing-notes).
La page indique que le code historique 6895 concernait toutes les zones sauf
les zones 80–85. WoWCarto Forever ne reproduit pas encore toutes les règles
historiques de restriction par zone : son édition locale est limitée aux zones
pour lesquelles une correspondance de carte 1.20 est disponible.

## Ajouter et modifier un point

1. Sélectionnez la base FR ou EN correspondant à la langue de l’information.
2. Sur la carte, faites un clic droit à l’endroit souhaité puis choisissez
   **Ajouter une annotation**. Un Maj+clic ouvre également l’éditeur.
3. Choisissez une catégorie, renseignez le nom et, si nécessaire, les niveaux,
   le commentaire et les propriétés. Validez avec **OK** ou **Ctrl+Entrée**.
4. Pour modifier une annotation existante, faites un clic droit sur son marqueur
   et choisissez **Modifier l’annotation locale**.

Les modifications restent sur votre ordinateur ; la base historique n’est pas
écrasée. Pour conserver une copie, utilisez **Sauvegarder le profil** dans le
menu de l’application. Sur les cartes Forever, les points utilisent la
correspondance géographique expérimentale avec la 1.20 : si aucun emplacement
correspondant n’est disponible, l’ajout est refusé. Les positions historiques ne
sont pas toutes vérifiées dans Forever.

## Partager

Un service public de contribution opérationnel n’a pas été validé. L’activation
du mode édition n’envoie pas automatiquement vos modifications. En attendant,
vous pouvez signaler une erreur dans une issue en indiquant la base, la région,
le point concerné et, si possible, sa position correcte.

Consultez aussi le [guide Windows](CLIENT_WINDOWS.md) et les
[informations pour contribuer](../CONTRIBUTING.md).
