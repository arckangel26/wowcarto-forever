# WoWCarto Forever

A Windows mapping companion inspired by WoWCartographe 1.20, built to explore
WoW Forever and consult historical community information.

Read the complete [French presentation](README.md) and the [Windows guide](docs/CLIENT_WINDOWS.md).

The first-run setup generates maps from the user's local WoW Forever installation,
then downloads verified French and English 1.20 reference databases. Consultation
works offline after setup. Historical entries and positions are not all verified
for Forever. An unsigned installer is available as a [preview release](https://github.com/arckangel26/wowcarto-forever/releases/tag/v0.9.2-preview) in this private repository.
